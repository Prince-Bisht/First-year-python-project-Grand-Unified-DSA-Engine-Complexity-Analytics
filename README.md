# ⚔️ Grand Unified DSA Engine & Complexity Analytics

A professional-grade, interactive 7-in-1 Data Structures and Algorithms (DSA) Visualizer built using **Python, Tkinter, and Matplotlib**. This application provides real-time graphical representations of core data structures along with dynamic asymptotic time complexity runtime profiling curves.

---

## 🚀 Key Modules Included

1. **💾 Linear Structures:** Live visual representation of **Arrays**, **Linked Lists** (Node-pointer pipelines), **Stacks** (LIFO simulation), and **Queues** (FIFO tracking tracks).
2. **🌲 Non-Linear Architectures:** Hierarchical structural layout for **Binary Search Trees (BST)** and an active **Hash Table** showing Linked Chaining collision resolution.
3. **🕸️ Network Graphs:** Dynamic node linkage visualization via custom adjacency matrices.
4. **📊 Complexity Analytics:** A specialized performance profiling suite leveraging **Matplotlib** to map real-time operational time complexity bounds ($O(1)$, $O(\log N)$, $O(N)$, $O(N \log N)$).

---

## 🛠️ Tech Stack & Requirements

* **Language:** Python 3.8+
* **GUI Engine:** Built-in Tkinter Framework
* **Data Visualization:** Matplotlib, NumPy
